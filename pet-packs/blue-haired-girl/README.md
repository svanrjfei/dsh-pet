# 小团团 · DSH 独立宠物插件

包名：`dsh-pet-xiaotuantuan`。复用 `dsh-pet` 的桌宠引擎，单独提供“小团团”角色、透明待机及拖拽动画，默认显示在桌面左下角。

## 安装

1. 在 DSH 插件管理中先安装并启用 `dsh-pet`（0.4.7 或兼容的 0.4.x 版本）。
2. 在“添加插件”的输入框粘贴 `dsh-pet-xiaotuantuan-0.1.14.tgz` 的**完整本地路径**，安装并启用；也支持直接填写本目录的完整路径。
3. 启用后插件会自动刷新桌宠。若 DSH 提示需要重启，先重启；若窗口未出现，右键原桌宠选择“重载配置”。浏览器界面需刷新。

本插件尚未发布到 npm，不能只输入包名下载。无需手动复制宠物文件，无需安装脚本审批。

源码安装的等价命令（在仓库根目录执行）：

```sh
dsh plugin --profile desktop add ./pet-packs/blue-haired-girl
```

## 启用、停用与数据

- 等待 `dsh-pet` 的宿主服务就绪后，才创建独立的 `blue-haired-girl` 宠物组；缺少依赖时保持等待。
- 不修改原宠物的 `main-config.jsonc`、内置配置或动画池。
- 平时播放待机动画，鼠标拖动时播放悬空蹬腿动画；自动余额、碎碎念、工作状态联动关闭。
- 停用或卸载时隐藏本组并自动刷新桌宠，保留素材及用户修改过的大小、名称、位置；再次启用会恢复。自动刷新失败时可右键原桌宠选择“重载配置”。
- 数据位于 `$DSH_HOME/dsh-pet/pet/`（默认 `~/.dsh/dsh-pet/pet/`）：启用配置是 `blue-haired-girl-config.json`，停用后保存为同名文件加 `.disabled`；素材在 `blue-haired-girl-animation/`。
- 如果此前手动安装了同名宠物包，本插件会报冲突并保留原文件；先备份移走旧组再启用。一个 DSH 数据目录只在一个 profile 中启用本插件。

更新旧版时，用新 `.tgz` 安装包重新安装本插件。首次升级会为旧版的空拖拽动画池补入新动作，保留其他设置和已有的自定义拖拽动作。0.1.2 会自动替换 0.1.1 的原装拖拽素材；通过文件摘要识别，用户自行替换的同名素材不会被覆盖。

右键小团团 → 动作 → 小团团出行 → 接你下班，可播放 5 秒三轮车动画。此动作不参与待机随机抽取，通过手动或定时播放；此动作禁止镜像以保持车牌文字方向。升级至 0.1.3 会补入菜单，不改动角色大小、位置或已有动画池。

0.1.4 新增右键 → 更多 → **小团团·接你下班**：车辆到达后显示“下班啦，快上车！小团团来接你～”，持续 3 秒；无需语音或模型服务。原“动作”入口仍是纯动画预览。招呼只响应本插件宠物；播放未开始、失败或在招手前被打断时不弹气泡。停用插件会注销菜单。

0.1.7 新增右键 → 动作 → **日常小动作 → 超大伸懒腰**：采用用户确认的 2 倍速，约 2.5 秒，已去背景和脚底阴影，并对齐待机角色的大小与脚底位置。0.1.8 默认每轮结束后以 80% 概率待机、20% 概率伸懒腰，不是固定时间间隔。升级会开启原装动画池的随机播放；已有自定义权重、分类、同名素材和角色设置保持不变。

0.1.9 加入 **哈欠连天**：5 秒原速，去背景与脚底阴影，与伸懒腰共同参与日常随机动作。当前默认（0.1.10）为 30% 待机、70% 日常动作；抽中日常动作时尽量避免连续重复。右键 → 动作 → 日常小动作也可手动预览。升级保留用户权重、角色设置及自定义同名素材。

0.1.10 将旧默认的 80% 待机 / 20% 日常动作升级为 30% / 70%，保留其他自定义权重。概率指每轮选片，不是播放时长占比。

0.1.11 加入 **悠闲哼歌**：5 秒原速，去除背景与脚底阴影，保留彩色音符；与伸懒腰、哈欠共同使用 70% 日常动作概率，待机仍为 30%。右键 → 动作 → 日常小动作可点播。

0.1.12 修复拖拽结束后停留在待机、不再随机播放的问题：余额事件改用独立名称“余额展示”（画面与待机相同），避免待机被误判为事件动画。升级只修正旧默认映射，保留自定义余额动作和 30% / 70% 权重。

0.1.13 加入 **东张西望**：5 秒原速，去背景和脚底阴影，左右张望后回正。它属于日常随机动作，不放入转向池、不触发角色镜像翻转；四个日常动作共同使用 70% 概率，待机保持 30%。

0.1.14 加入 **玩游戏气急败坏**：10 秒原速，保留玩游戏、摔机、抱头跺脚和恢复站姿的完整动作，去除背景与脚底阴影。与现有四个日常动作共同使用 70% 概率，待机仍为 30%。

## 定时接你下班

在 **DSH 设置 → 小团团** 中打开“定时接你下班”，选择时间和重复星期，点击保存即可生效。默认关闭，预填周一至周五 18:00；使用电脑本地时间。到点自动播放三轮车动画并弹出招呼气泡，不调用模型或语音。

DSH 和插件需保持运行，宠物需显示在桌面。错过的分钟不补播；同一计划分钟重启不重复播放。播放失败不重试，等待下次计划。设置保存在 `$DSH_HOME/dsh-pet/xiaotuantuan-schedule.json`，升级和停用保留。

## 开发与打包

```sh
npm ci
npm test
npm pack
```

使用原生 JavaScript，无构建步骤；npm 打包自动运行测试。当前配置面向 DSH 0.2.2-rc.1，未声明其他版本已经实测兼容。

动画为 640×360、24 fps、10 秒 VP9 Alpha WebM，无音轨；已去绿色背景、外围水印及脚下椭圆阴影，末尾 0.5 秒过渡回起始姿态。拖拽动画为同画布的 10 秒、24 fps VP9 Alpha WebM，无音轨；采用新版站立→抓起→悬空蹬腿→落地动作，原速播放，已去背景、外围水印及脚下阴影，末尾 0.25 秒过渡回起始姿态。

支持 Chromium / Electron；未提供 Safari 所需的 HEVC Alpha MOV。
